Due to limitations of Tecan touch tools, this is ment to act as a touch friendly replacement UI for selecting pipetting scripts and inputing relevant parameters for pipetting tasks (like start position, sample count, pipetting volume, user defined). Contains graphical representations and touch selection of 96 well layouts, which was lacking in touch-tools. It reads/writes values (parameters) to txt files for evoware to use.

Test scripts etc... are added and can be deleted.
